Checklist antes de hacer push:
0. git checkout develop
1. git pull origin develop
2. git checkout -b feature/...
3. pnpm format
4. pnpm lint
5. pnpm typecheck
6. pnpm build
7. pnpm format:check
8. git status
9. add .
A. git commit -m "..."
B. git checkout develop
C. git merge feature/...
D. git push origin develop
E. git branch -d feature/...
F. git push origin --delete feature/...


Formato para commits:
tipo(scope): descripción

Tipos de commits:
feat: Nueva funcionalidad.
fix: Corrección de bugs o errores.
style: Cambios de formato visual del código.
refactor: Cambios en código interno sin agregar features ni arreglar bugs visibles.
chore: Tareas de mantenimiento o tooling.
docs: Documentación.
test: Cambios relacionados con pruebas.
